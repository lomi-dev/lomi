# Provider icons

The OpenAI, Anthropic, xAI, OpenRouter, DeepSeek and NVIDIA SVGs were
supplied for this application. OpenAI and xAI use tighter view boxes;
NVIDIA shows the symbol without the wordmark at small sizes. CSS masks
render these assets in the current theme's foreground color.

The Google G asset comes from
[Google's branding assets](https://developers.google.com/static/identity/images/g-logo.png)
and retains its original colors.
