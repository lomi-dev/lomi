# Interface translations

Lomi ships English (source), Polish, German, Russian, Ukrainian, Italian and
Spanish. `src/i18n.ts` owns the active language; `src/locales/<code>.json`
holds one dictionary per language. English needs no file.

## Language selection

- On the first launch the first supported system language
  (`navigator.languages`) is chosen, otherwise English. The choice is stored
  in webview storage (`lomi.locale.v1`), so later system changes never switch
  the interface.
- Settings → General → Language switches it live, without a restart.

## Writing translatable code

English source text is the key. Missing translations fall back to English.

```tsx
import { useT } from "./i18n";

function Example({ name, count }: { name: string; count: number }) {
  const { t, tp } = useT(); // subscribes the component to language changes
  return (
    <button title={t("Open {name}", { name })}>
      {tp(count, "{count} file", "{count} files")}
    </button>
  );
}
```

- In React components call `useT()` once at the top (before any early
  return) and use its `t`/`tp`. Outside components (callbacks in plain
  modules, thrown errors that reach the UI) import `t`/`tp` from `./i18n`;
  they translate at call time.
- The key must be a double-quoted string literal written directly in the
  call: `t("Save")`. No template literals, concatenation or variables, or
  `scripts/i18n-check.mjs` cannot find it.
- Translate whole sentences, including punctuation. Put dynamic values in
  `{name}` placeholders instead of concatenating fragments.
- Counts use `tp(count, one, other, vars?)`; `{count}` is filled
  automatically. Translations provide the CLDR forms their language needs
  (`one`, `few`, `many`, `other`).
- Module-level constants (menus, option lists) wrap their literals in
  `msg("…")` and are rendered with `t(label)`.
- Do not translate identifiers, stored values, values compared elsewhere in
  code, console output, CLI commands, paths, key names, product names
  (Lomi, Git, GitHub, Claude Code, Codex, Android…) or text that comes from
  the native side.

## Dictionaries

A dictionary maps the English key to a string, or for `tp` keys to an object
of plural forms:

```json
{
  "Save": "Zapisz",
  "{count} files": {
    "one": "{count} plik",
    "few": "{count} pliki",
    "many": "{count} plików",
    "other": "{count} pliku"
  }
}
```

`pnpm i18n:check` lists missing keys and placeholders that differ from the
key for every language; `node scripts/i18n-check.mjs --keys` prints all keys
with the files that use them.
