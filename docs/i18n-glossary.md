# Translation glossary

Lomi is a desktop workspace for developers: projects, workspaces, tabs,
terminals, an editor, Git and AI agents in one window. Translate for
developers: short, plain interface language as in the platform's own
software (macOS, VS Code, GitHub) in that language.

## Always keep in English

Lomi, Git, GitHub, CLI, MCP, API, SDK, AVD, ADB, AOSP, Google Play, VS Code,
Claude Code, Codex, Cursor, Kimi, Antigravity, OpenAI, Anthropic, Android,
macOS, Windows, Linux, PowerShell, WSL, JSON, JSONC, URL, HTTPS, SSH,
Markdown, ANSI, IME, PTY, keyboard key names (Ctrl, Shift, Enter, Esc, Tab),
commands and code (`gh auth login`), file names and paths, `{placeholders}`.

## Tone

| Language       | Address                            | Notes                                     |
| -------------- | ---------------------------------- | ----------------------------------------- |
| Polish (pl)    | informal imperative, no "Pan/Pani" | "Dodaj projekt", "Wybierz folder"         |
| German (de)    | "du"                               | sentence case for labels                  |
| Russian (ru)   | "вы" (lower case)                  |                                           |
| Ukrainian (uk) | "ви" (lower case)                  | modern Ukrainian IT terms, no Russianisms |
| Italian (it)   | "tu"                               |                                           |
| Spanish (es)   | "tú", neutral Spanish              | no regionalisms                           |

Buttons and menu items are short verbs. Keep the source's capitalization
style: sentence case, no added title case.
