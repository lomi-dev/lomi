Lomi 0.7.0 rebuilds Chat AI on your own API keys and the coding-agent CLIs already installed on your computer, redesigns Settings and translates the interface into six languages.

- Chat with Anthropic, OpenAI, Google AI Studio or any compatible API, or with Claude Code, Codex, Kimi Code and Antigravity using your existing CLI login. Installed CLIs are detected and added automatically, with their subscription plan and version.
- Choose models per provider with favorites, ordering and custom models; set the default model, reasoning effort, fallback model, permissions (read-only by default) and starting folder for new chats.
- Attach images, PDFs and text files by picking, dragging or pasting them. Change reasoning effort per chat, and split chats side by side like terminals within a minimum readable size.
- Keep chat history per workspace and confirm before replacing a chat that has messages.
- Find any setting with the new Settings search, in a redesigned sheet with a terminal font preview, theme previews, a simpler Keybinds page, rebuilt Plugins and Agent control pages and a clearer Android setup.
- Use Lomi in English, Polish, German, Spanish, Italian, Russian or Ukrainian.
- Start projects from a new folder, a local folder, a Git URL or a GitHub repository, with first-run onboarding.
- Show project logos for workspaces: a custom logo, the project favicon or the GitHub owner avatar. Edit a workspace's name and logo in one dialog.
- On macOS, press ⌘Q twice (or hold it) to quit, with a visible hint; the disk image has a new background.

Compatibility: CLI Accounts, durable agent tasks and the Agents launcher are removed. CLI chats now run the system-installed CLI with your own login and version instead of isolated, pinned copies. Saved agent-task tabs are dropped when a session loads. Data from the previous Chat AI and agent runtime stays on disk untouched. Chat providers from 0.6.x are re-detected automatically; API providers and keys are kept.

Remote hosting remains enabled only on macOS Apple Silicon. On macOS and Linux, closing the workspace window keeps Lomi running in the background; Quit Lomi ends its sessions.
