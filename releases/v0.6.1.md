Lomi 0.6.1 brings Settings into the workspace, replaces legacy CLI routing with a durable account and task runtime, and unifies notification controls.

- Open preferences in one reusable Settings tab while preserving running terminals, editor history and form drafts.
- Keep native CLI task history across attempts and explicit account changes, with guarded continuation and recovery for uncertain work.
- Enable desktop and phone notifications independently for task and Chat completions, and forward supported terminal attention signals to your phone. Notifications are opt-in and disabled by default.
- Keep application, Android and MCP alerts in the persistent notification inbox, including retry and recovery actions. Preserve inbox files written by newer versions.
- Copy files into Explorer with drag and drop, automatically expand hovered folders, and preserve existing files on name conflicts.
- Save edits and stop owned runtimes through guarded quit when closing the Windows window; reopen the running instance on subsequent launches.
- Preserve native keyboard exception handling on macOS for more stable input.
- Keep account sign-in usable with a disclosed session-only login when the system key store is unavailable, and show clearer Remote service errors.
- Request explicit Cursor Keychain authorization before reading protected usage credentials; background checks remain noninteractive.

Compatibility: legacy router Text, Coding and Gateway execution modes are retired. Existing history is imported or archived instead of executed through the old router. Native CLI capabilities that have not passed the required qualification remain unavailable; this release does not qualify every CLI or platform. Independent Chat AI API connections remain available.

Remote hosting remains enabled only on macOS Apple Silicon. On macOS and Linux, closing the workspace window keeps Lomi running in the background; Quit Lomi ends its sessions.
