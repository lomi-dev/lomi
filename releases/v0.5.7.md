Lomi 0.5.7 improves Remote workspace reliability and adds native CLI routing.

- Preserve active Remote sessions when account access and workspace approvals renew.
- Pause Remote after more than one hour without terminal or window activity, and resume it without restarting local terminals or losing workspace sharing consent.
- Recover the terminal helper from bounded checkpoints and ordered output journals; isolate terminal state that cannot be recovered safely.
- Stop workspace sharing even when a terminal's Remote model is unavailable.
- Prevent delayed Stop requests from retiring a newly shared workspace during pause, Resume or re-sharing.
- Explain Remote hosting availability and the total desktop terminal budget before sharing.
- Add native CLI account routing and explicit, guarded transfer of saved run history.
- Add Custom API connections for Chat Completions, Responses and Anthropic Messages, with optional authentication and manually configured models.
- Use portable secure identifiers for native CLI routing and notification backups on Windows.
- Clear all local notifications through the notification inbox action.
- Require account, workspace, terminal observer, helper and Remote UI regressions before release packaging.

Remote hosting remains enabled only on macOS Apple Silicon, with a total limit of 32 active desktop terminals across all workspaces, including unshared terminals. Live connections use end-to-end encryption; offline mailbox access remains disabled. Closing the workspace window keeps Lomi running in the background; Quit Lomi ends its sessions.

The browser Remote client is deployed separately. Its matching update scopes workspace connections to the accepted signed access grant and safely retires terminal callbacks when their view is removed.
